# Motion Dojo — Resource Index (linked, no searching required)

Everything you need is here. If a rep prompt needs a resource, it's linked below by phase. Do not search for anything else — if you think you need a new resource, add it to the "needs" list and check with Claude in your weekly critique, per the curriculum's own rule ("no new library on a rep day").

Rewritten 2026-09-23 to match the current 5-phase curriculum (`curriculum.json` / `Claude outputs/motion-dojo-curriculum.md`) — the previous version of this file still described an earlier 7-phase scheme (Weight/Timing, Type as material, Sequencing, Transitions, Scroll, 3D, Sound) that predates the director-level rewrite. Links are carried forward; only the phase grouping changed.
